# scx_pre_fork 内存泄漏修复记录

## 根因分析

**内核漏洞**：`CONFIG_SCHED_CLASS_EXT=y` 时，`scx_pre_fork` 在每次 fork 时分配 256 字节但不释放。

```
kernel_clone → copy_process → sched_fork → scx_pre_fork → kmalloc(256) [泄漏]
```

- 设备内核：`6.1.118-android14`
- 符号地址：`scx_pre_fork` = `ffffffded131224c`
- 对应 free 函数：`sched_ext_free` = `ffffffded1312c48`

## 缓解措施（已实施）

### 修改 net_turbo_pro

文件：`/data/adb/modules/net_turbo_pro/scripts/nt_watch.sh`

修改：第105行
```bash
# 原值
FAST_INTERVAL=${NT_FAST_INTERVAL:-5}

# 修改后
FAST_INTERVAL=${NT_FAST_INTERVAL:-60}
```

效果：
- 修改前：440 objects/秒
- 修改后：68 objects/秒
- **减缓约 6.5 倍**

### 备份文件

原始文件已备份：`nt_watch.sh.bak.YYYYMMDD_HHMMSS`

## 后续方案
